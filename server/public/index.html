星星战GTA5Online 联机中心

用户名 3～20 位，可用中文、字母、数字、下划线；密码至少 8 位。

非官方的玩家自建服务，与 Rockstar Games 无关。需要自备正版 GTA V。

在线房间

三种玩法：赛车、团队竞技（在自己创建的房间里由房主开启）和个人对战（公共对战房，一直开放）。在手机联机页点“创建房间”“在线房间”或“进入公共对战房”即可，全部通过服务器联机，不需要同一 Wi-Fi、热点或组网软件。

我的角色

角色名就是你在联机房间里显示的名字，全服唯一，创建后不能修改。

排行榜

按街头赛车胜场排序（至少 2 人参赛才算胜场）。赛车成绩由房主的游戏上报，团队竞技战绩由每位玩家的游戏上报，仅供娱乐。
