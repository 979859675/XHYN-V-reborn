在线房间

房主在游戏里创建房间后会显示在这里。把房主 IP 和房间码填进游戏的“加入房间”即可。标着“虚拟局域网”的房间需要先连上同一个组网。

我的角色

角色名就是你在联机房间里显示的名字，全服唯一，创建后不能修改。
