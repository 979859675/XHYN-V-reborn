# 小春GTA5Online online12

可直接覆盖安装在 online9 / online10 / online11 之上。**服务器需要同步更新**（`server/src/app.js`、`server/src/relay.js`、`server/src/db.js`、`server/public/app.js`、`server/public/index.html`、`server/public/style.css`，然后重启；新表自动创建）。

## 变化

- **公共对战房（个人对战）**：联机页新增“公共对战房”按钮，随时可进，不用房间码。没人时第一个进的人自动当房主；房主离开后，其他人自动重新进入，最先回来的人接任房主；满 10 人自动开下一间。
- 个人对战不分队、不限时：各打各的，只累计自己的击杀和阵亡，数据永久保存在服务器。摔死、被警察打死只记阵亡。公共房不放人机。
- 网页“排行榜”新增个人对战榜：今日 / 本周 / 总榜；“管理”页新增个人对战记录（每人累计、击杀明细、清零）。
- **名字颜色**：团队竞技里红队名字红色、蓝队名字蓝色（头顶名字、悬浮窗、网页）；公共对战房里其他玩家的名字都是红色。

## 已知限制

- 房主离开时，房间里的人会断开几秒再重新进入。
- 每间公共对战房仍是 10 人。
