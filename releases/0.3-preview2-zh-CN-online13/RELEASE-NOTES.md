# 小春GTA5Online online13

可直接覆盖安装在 online9～online12 之上。服务器只需更新网页两个文件：`server/public/app.js`、`server/public/index.html`（不用重启也可以，刷新网页即可）。

## 变化

- **复活后黑屏的自救**：这是原版游戏的问题（原版也要自杀两三次才恢复）。现在屏幕顶部开着帧率显示时，程序发现复活后画面停住会自动替你执行“自杀”直到恢复；悬浮窗里也有“黑屏自救”按钮可以手动点。自救造成的阵亡不计入个人对战和团队竞技战绩。
- **只保留服务器联机**：去掉了同一 Wi-Fi、热点和虚拟局域网联机，以及“公网联机”开关。创建房间一律走服务器；加入房间只能在“在线房间”里点选，点了直接加入。
- **联机页显示支持的玩法**：赛车、团队竞技、个人对战三张卡片，各带说明和入口按钮（创建房间 / 在线房间 / 进入公共对战房）。
- 进入任何联机房间后悬浮窗都会显示（之前没有比赛时非房主看不到）。

## 已知限制

- 自动自救依赖屏幕顶部的帧率显示（“原生FPS”一栏）；没开时只能手动点按钮。
- 自救本质上是再死一次，每次仍要等几秒。
