# 星战GTA5Online · 测试版 15（游戏内简体中文）

功能与 online14 相同，这一版把**游戏本体的语言**改回简体中文。包名不变（`cn.xzcqgzs.zy`），可直接覆盖安装 online14。

## 改动
- 游戏内文本（菜单、字幕、任务提示等）固定使用游戏自带的**简体中文**语言包和字库。
- 做法：底包的引擎 `libgtav.so` 被上游英文版改成了强制英文（`modifications/english-1.7.4/patch_native_english.py`），本版在打包时把其中 12 处（46 字节）按原值改回：语言编号 13、亚洲文字排版、`chinese` / `chinesesimp` 字库与语言包名。每处改前都校验原字节。
- 保留上游去掉的“系统语言必须是中文”限制，手机系统是任何语言都能用。

## 须知
- 语言固定为简体中文，没有中英切换。
- 简体语言包（`chinesesimp*.rpf`）和字库在导入的游戏数据里，不在安装包里。数据包若被精简到只剩英文，文字会显示成标签名或方块，需要换完整数据包。
- `commandline.txt` 里的 `-uilanguage` 对这个移植版不起作用，可以删掉。
