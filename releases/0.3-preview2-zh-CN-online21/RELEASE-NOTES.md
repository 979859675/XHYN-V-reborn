# 星战GTA5Online 0.3-Preview2 online21

## 每个玩法只显示自己的悬浮窗
- 联机页的“赛车”卡片现在创建的是**赛车房**，“团队竞技”卡片创建的是**团队竞技房**，房间名分别是“某某 的赛车房”“某某 的团队竞技房”。
- **赛车房里不再弹出团队竞技悬浮窗**（房主和加入的人都一样）。
- 团队竞技房显示团队竞技悬浮窗；个人对战（公共对战房）显示个人对战悬浮窗。
- 两张卡片的房间列表各自只列出本玩法的房间。旧版本创建的房间不带玩法，两个列表里都会出现，进去后按旧方式显示悬浮窗。
- “个人对战”卡片的说明更新为新规则（先到 20 分、10 分钟、连杀悬赏、赛季段位）。

## 说明
- 赛车房里没有悬浮窗，所以也没有手动“黑屏自救”按钮；打开帧率显示后的自动自救仍然有效。
- 不需要更新服务器就能用。服务器网页（新外观、分页）是另一项更新，单独部署 `server/` 即可。
- 本版本只通过了编译，未在真机上验证。
