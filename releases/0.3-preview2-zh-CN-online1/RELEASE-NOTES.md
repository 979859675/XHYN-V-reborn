在 [启动器汉化版](../../releases/tag/v0.3-preview2-zh-CN) 的基础上，给“联机”页加了**联机中心**。非官方修改，未经真机测试。

## 新增

- “联机”的三个页面顶部多了“联机中心”卡片：登录 / 注册、选择或创建角色、退出登录。
- 联机昵称改为使用角色名，不能再手动输入。
- “加入房间”页多了“在线房间”按钮：选一个房间，自动填好房主 IP 和房间码。
- 房主创建房间后，房间会自动出现在在线房间列表里，关闭后自动消失。
- 在房间内游玩时累计角色的在线时长。

## 需要知道的

- **不登录就不能创建或加入房间。** 登录过一次后，即使联机中心暂时连不上，也可以继续用局域网联机。
- 联机中心地址固定为 `https://zy.xzcqgzs.cn`，账号和网页版通用。
- 房主的 IP 会展示给所有已登录的玩家。
- 联机方式没有变：仍然要在同一 Wi-Fi / 热点，或同一个虚拟局域网里。这一版**不包含**公网中转。
- 比赛成绩还不会上报，排行榜暂时没有数据。

## 安装

- 已装汉化版：直接覆盖安装，数据保留。
- 装的是官方版：签名不同，需要先卸载官方版（会清除它的数据）。

## 改动范围

相对汉化版只改了 `classes10.dex`（两处调用）并新增 `classes12.dex`（联机中心代码），其余文件逐字节相同。源码和构建脚本在 `modifications/online/`。
