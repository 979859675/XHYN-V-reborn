# 星战GTA5Online · 测试版 19（必须登录 + 登录背景图）

功能与 online18 相同，可直接覆盖安装。

## 改动
- **必须登录或注册才能进入**：打开应用先显示全屏登录界面，登录/注册成功后才能看到启动器。没有“暂不登录”，点返回键是退到桌面。
- 登录界面使用新的**背景图**，上面是用户名、密码、邀请码（仅注册时填写）、登录 / 注册按钮，底部显示官网和 QQ 群。
- 退出登录、或服务器判定登录已失效时，会立刻回到登录界面。
- 已登录的手机再次打开不需要重新登录；只是连不上服务器时，保留本机的登录状态照常进入。

## 须知
- 新装的手机必须联网并能访问服务器才能进入，单机也一样。服务器停机时，没登录过的手机进不去。
- 背景图打包在安装包里（`assets/online/login.jpg`），换图需要重新出包。
