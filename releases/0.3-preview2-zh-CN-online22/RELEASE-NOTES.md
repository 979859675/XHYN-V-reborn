# 星战GTA5Online 0.3-Preview2 online22

**需要同时更新服务器**：重新部署 `server/` 并重启。服务器没更新时，新建的个人战房不会计分，也不会出现悬浮窗。

## 个人对战改成和另外两个玩法一样
- 不再是单独的“公共对战房”。联机页“个人对战”卡片现在是两个按钮：**创建个人战房**、**个人战房列表**。
- 自己创建的房间叫“某某 的个人战房”，最多 10 人，创建的人是房主。
- 列表里能看到每个房间的房主和**在线人数**（如“在线 3/10 人”），满员的会标“已满”，点一下加入。
- 赛车房、团队竞技房的列表同样显示在线人数。
- 进入个人战房后只显示个人对战悬浮窗；规则不变（每局先到 20 分、10 分钟、连杀悬赏、赛季段位）。

## 和以前不同的地方
- 房主退出后房间关闭，不会再自动换房主；其他人会收到提示，需要重新创建或加入别的房间。
- 网页“在线房间”里不再有常驻的“公共对战房 1”占位，房间带“赛车 / 团队竞技 / 个人对战”标签。

## 说明
- 本版本只通过了服务器自动测试和编译，未在真机上验证。
