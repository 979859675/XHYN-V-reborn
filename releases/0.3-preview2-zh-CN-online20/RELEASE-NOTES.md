# 星战GTA5Online 0.3-Preview2 online20

**需要同时更新服务器**：把仓库里的 `server/` 重新部署并重启，否则新功能不会出现（旧服务器下游戏照常能玩，只是没有回合、连杀和段位）。

## 新增

### 个人对战：抢人头赛 + 限时赛
- 公共对战房现在按“局”进行：**先到 20 分获胜**；**10 分钟**到点时按得分定胜负。
- 一局结束后悬浮窗显示冠军和前三名，**15 秒后自动开始下一局**（休息时间不计分）。
- 没有人得分时不结算，继续打。
- 服务器 `.env` 可改：`FFA_TARGET`（目标分）、`FFA_MINUTES`（每局分钟数）。

### 连杀与悬赏（个人对战、团队竞技都有）
- 连杀 3 / 5 / 7 次，全房间弹出公告。
- 连杀 3 次以上的玩家**头顶名字变金色**，悬浮窗里标“悬赏中”。
- 击杀他：个人对战得 **2 分**；团队竞技本队得 **2 分**。

### 段位与赛季
- 段位：青铜 0 · 白银 100 · 黄金 250 · 铂金 500 · 钻石 900 · 星耀 1400 · 王者 2000。
- 积分：击杀 +2（终结悬赏 +4），阵亡 −1（不会低于 0）；个人对战每局前三名 +25 / +15 / +8；团队竞技获胜 +20、平局 +5。
- 团队竞技至少要有 2 名真人才计段位分，击倒人机不计分。
- 悬浮窗显示自己的段位和距离升段还差多少分；网页“排行榜”新增**赛季段位榜**和上赛季前三名。
- 一个赛季默认 30 天（`.env` 的 `SEASON_DAYS`），到期自动清零开始下一赛季；管理员可在网页“管理”里提前结束。

## 说明
- 战绩由各玩家的游戏上报，不防作弊。
- 本版本只通过了服务器自动测试和编译，未在真机上验证。
