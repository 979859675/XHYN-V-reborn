The graphics output could not be initialized => 无法初始化图形输出。请完全关闭并重新打开游戏，尝试关闭插帧，并检查所选的驱动和渲染器。如果问题重复出现，请保存报告。此提示并不表示你的游戏目录无效。
The engine stopped at an internal assertion => 引擎在一处内部断言处停止，且没有给出具体错误代码。这不是正常退出。请保存报告（含调用栈和资源日志），以便定位出错的子系统。
The PanVK driver reported GPU job faults => PanVK 驱动报告了 GPU 作业错误。请在关闭插帧和性能提示的情况下对比同一场景，然后保存报告。是否支持取决于具体的 GPU 和驱动；本报告不代表所有 Mali 设备都适用。
The engine could not read an archive header => 引擎无法读取某个归档文件头。请查看资源日志中指出的具体文件，并使用匹配的 GTA V Legacy 资源。定位该文件不需要完整扫描游戏文件。

The game engine stopped after an error => 游戏引擎在出错后停止。报告已保存在本设备上，请分享它以便排查原因。
There is no saved explanation for the last attempt yet => 目前还没有上一次运行的说明。请打开“录制下一次游戏”，重现问题，然后选择“保存报告以便分享”。
Some graphics settings could not be applied. Your saved => 部分图形设置未能应用，已保留你保存的配置。请检查 dxvk.conf，或打开技术详情查看具体是哪项设置。
The engine could not use a game resource safely => 引擎无法安全地使用某个游戏资源。原因可能是数据不兼容，或引擎的资源处理存在问题。请保存报告，以便排查受影响的资源。
A graphics memory allocation failed => 图形内存分配失败。请尝试降低纹理、分辨率和抗锯齿，这可以减少内存需求；确定具体原因仍需要报告。
The graphics device stopped responding => 图形设备停止响应或无法启动。请关闭游戏，然后尝试兼容的驱动或渲染器。降低画质设置可以减轻负载。如果再次发生，请保存报告。
The selected graphics renderer could not use this GPU => 所选的图形渲染器无法使用此 GPU 或驱动。请在“Vulkan 驱动”中运行可选的图形检查，然后尝试兼容的渲染器或驱动。小型测试通过并不保证游戏能够运行。
The game scripts asked for functions => 游戏脚本请求了此引擎未提供的函数。请使用与本版本匹配的游戏和脚本文件。请保存报告，以便定位出错的脚本。
The engine detected damaged memory => 引擎检测到内存损坏。这并不能证明是内存耗尽。请保留报告，并记下当时是否开启了录制、插帧或模组。保护机制已保留；更早发生的错误写入仍需排查。

May reduce texture shimmering => 在受影响的游戏中可以减轻纹理闪烁和采样压力，但细节会变得柔和。如果游戏没有使用负偏移，则可能没有效果。
May reduce synchronization cost => 可能降低同步开销，但也可能引入渲染错误或设备丢失。除非在做受控的稳定性/性能测试，否则请保持“默认”。
A shader-correctness workaround => 这是针对着色器正确性的规避手段，会增加初始化工作，可能降低帧率。
Lower filtering can reduce GPU sampling cost => 降低过滤等级可以减少 GPU 采样开销。提高过滤等级能改善斜向纹理，但可能降低帧率，或改变需要特定采样器的效果。
Overlap can improve throughput => 重叠可以提高吞吐量。禁用后可能降低队列延迟，但也可能降低帧率。仅对相应的低延迟模式生效。
Helps compare renderer behavior => 有助于对比渲染器行为和诊断变慢的原因。显示额外的测量数据会增加一些开销；叠加层本身不会提高帧率。
Can reclaim wasted allocation space => 可以回收浪费的分配空间，但需要移动内存，可能造成卡顿或驱动相关的问题。“自动”遵循渲染器的兼容性策略。
Can reduce GPU work, bandwidth and render-target memory when MSAA => 当 MSAA 生效时，可以减少 GPU 工作量、带宽和渲染目标内存。边缘质量会下降，部分渲染路径可能需要其正常的 MSAA 行为。
Can reduce shader-compilation pauses => 在支持的版本中可以减少着色器编译造成的停顿。部分物体或效果可能要等着色器编译完成后才出现。结果取决于渲染器和场景。
Primarily a quality option => 主要是一项画质选项。配合 MSAA 时通常会增加 GPU 工作量，并可能明显降低帧率。
May change texture-streaming decisions => 当游戏误判可用内存时，可能改变纹理流式加载的决策。上报值偏低会导致额外的流式加载；上报值偏高并不能增加物理内存。
Can help investigate context races => 有助于排查上下文竞态。加锁会带来开销，可能降低 CPU 吞吐量；它并不能修复所有崩溃。
Mainly affects the game => 主要影响游戏对内存的估算。调高它一般不会提升帧率，物理内存也不会改变。
A compatibility limit can change which features => 兼容性限制会改变游戏请求哪些功能。DX10.1 还可能导致无法启动。调低它并不会消除渲染器对 Vulkan 的要求，也不保证游戏更流畅。
More workers can shorten shader preparation => 线程越多，着色器准备越快，但会与游戏争抢资源并增加发热/内存占用。在 CPU 性能有限的设备上，“自动”或较少的线程数可能让游戏更稳定。
Primarily prevents visible depth conflicts => 主要用于避免可见的深度冲突。可能带来少量性能开销；关闭后可能重新出现闪烁。
A reusable cache can reduce repeated preparation => 可复用的缓存可以减少后续运行时的重复准备工作。在所有着色器都已就绪后，它并不保证更高的帧率。
Trades input latency, CPU/GPU overlap and throughput => 在输入延迟、CPU/GPU 重叠和吞吐量之间取舍。“最低延迟”可能降低帧率；输出是否更平滑或更跟手，需要在所选设备上实测。
May reduce pipeline-memory pressure => 可能减轻管线内存压力。重新创建已释放的内容会增加 CPU 开销或卡顿；未使用管线库时此选项无效。
A texture-correctness workaround => 这是针对纹理正确性的规避手段。替代的传输路径可能有性能代价；它不是通用的帧率优化。
A lower limit may reduce GPU geometry work => 较低的上限可以减少使用曲面细分的场景中的 GPU 几何工作量。场景未使用该功能时影响很小。
Can reduce buffer-view overhead => 在合适的硬件上可以减少缓冲区视图的开销。在对齐不兼容的设备上强制开启可能破坏渲染；建议从“自动”开始。
Adds synchronization and may reduce shader/compiler efficiency => 会增加同步，可能降低着色器/编译器效率。适用于排查正确性问题；通常不会提升性能。
May speed CPU readback => 可能加快 CPU 回读，但会增加 GPU 访问或传输的开销。请在测得回读瓶颈时使用，不要把它当作通用的内存加速手段。
May reduce synchronization waits => 可能减少引擎与定制渲染器之间的同步等待。更改可能影响正确性或稳定性，请同时对比画面和帧节奏。
Can reduce or increase driver-side binding overhead => 可能减少也可能增加驱动侧的绑定开销。结果取决于驱动；对本移植版尚未确认有帧率提升。
Usually adds substantial CPU work => 通常会明显增加 CPU 工作量。请用它排查缓冲区初始化错误，而不是用来提高帧率。
Positive bias may reduce texture bandwidth => 正偏移可以减少纹理带宽和缓存需求，但纹理会变得柔和。仅更改采样偏移并不会释放已分配的高分辨率 mip 数据。
May improve submission behavior => 在部分移动 GPU 上可能改善提交行为，在另一些上则可能变差。效果需要设备对比；强制开启并不是通用的移动端优化。
